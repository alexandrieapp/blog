*Les applications se complexifient. D’une part, elles externalisent certaines tâches vers d’autres applications. D’autre part elles deviennent une source de donnée pour d’autres applications. Voyons comment Alexandrie relève ce défi.*

---

### Alexandrie est synchronisé avec le FEL (DILICOM)

Alexandrie intègre toutes les mises à jour du FEL à votre boutique Shopify. Le FEL est mis à jour quotidiennement à 6h30 du matin. Dès qu’une notice est mise à jour dans le FEL, la mise à jour est répercutée dans votre boutique Shopify.

### Alexandrie synchronise vos stocks avec des applications tierces

Alexandrie fait remonter vos stocks sur les principaux sites interprofessionnels : 

- Place des libraires
- Paris Librairie

Chaque jour, une image de votre stock est envoyée afin de maintenir vos offres à jour.

Alexandrie fait également remonter vos stocks sur le Pass Culture en temps réel.
